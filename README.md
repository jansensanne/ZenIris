# ZenIris

ZenIris is a high-performance, real-time data processing system built on a multi-threaded, distributed platform architecture.

ZenIris is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ZenIris.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

ZenIris is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
